
# Spam Email Detector

This project is based on Machine Learning for spam message detection.

## Features

* Spam Message Detection
* Text Preprocessing
* TF-IDF Vectorization
* Model Training & Testing
* Accuracy Comparison
* Custom Message Prediction
* Model Saving with `.pkl` files

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Seaborn
* Google Colab

## Dataset

* UCI SMS Spam Collection Dataset
* 5,574 labeled SMS messages (Spam / Ham)

## Machine Learning Models Used

* Naive Bayes
* Logistic Regression
* Linear SVM
* Random Forest

## Expected Accuracy

* Around **97% – 98%** accuracy on test data
